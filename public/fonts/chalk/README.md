# Munny Shop

Sign-derived uppercase display font for native Autoloot browser sources. A, U, T, O, L, W, E, C and M are traced from the generated project sign `shop-interior-v3.png`. Other letters, digits and punctuation use original rounded stroke drawings. Scalable pores add chalk grain. Lowercase maps to capitals; digits have equal advances. Licensed under MunnyShop-OFL.txt. Patrick Hand remains a separate legacy asset with its original OFL.txt.

Rebuild: `python3 creative/video/munny-shop/scripts/build_font.py` (Pillow, NumPy, OpenCV, fontTools).

Browser overlays load the compressed `MunnyShop-Regular.woff` export; the TTF remains the editable/installable source.
