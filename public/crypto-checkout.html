USDC on Solana

Enable wallet checkout

Set REOWN_PROJECT_ID, SOLANA_USDC_RECIPIENT and SOLANA_PAYMENT_RPC_URL in your server environment, then restart Autoloot. Use a Reown project ID from dashboard.reown.com, your merchant Solana wallet address, and an HTTPS mainnet RPC endpoint. Allow your storefront origin in the Reown dashboard. Never enter a wallet seed or private key.

Run npm ci and npm run build:wallet when deploying. npm start builds the optional browser bundle automatically.

Buyer flow

Sign in with Twitch, reserve a physical item, add a shipping address and choose Pay USDC · Solana in Your orders. Scan the Reown / WalletConnect QR with a compatible Solana wallet. The price is one USDC per USD of the displayed order total, plus wallet network fees paid in SOL. Confirm the exact asset, total and recipient in your wallet.

Verification & recovery

The server verifies finalized mainnet USDC, recipient, exact amount and a unique order memo. A submitted signature or wallet success message is not payment proof. Save the transaction signature from your wallet; if confirmation is delayed, return to the order and verify it. Do not pay twice.

A wallet quote locks the order against Stripe checkout, automatic reservation expiry and ordinary cancellation. If no payment was sent, use Cancel expired wallet checkout after its blockhash expires. The server checks for a matching finalized transfer before releasing stock; if RPC evidence is incomplete it keeps the order reserved for reconciliation.

Wallet payments are available for physical live orders only. No crypto payments are simulated in practice mode. Crypto refunds are handled separately by the seller; Autoloot does not automatically send refunds or control seller funds. NFT purchases continue to use Stripe. Rehearse wallet connection, mainnet verification, cancellation and fulfillment before enabling this on a real show.
